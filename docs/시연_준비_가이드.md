# 시연 준비 가이드 (macOS)

맥북에서 터미널을 처음 여는 것부터 UAT 시연까지 순서대로 따라 하면 됩니다. 회색 상자 안의 명령어는 한 줄씩 복사해서 터미널에 붙여 넣고 Enter를 누르세요.

---

## 1. 터미널 열기

1. `Cmd + Space`를 눌러 Spotlight를 엽니다.
2. `터미널` 또는 `Terminal`을 입력하고 Enter를 누릅니다.
3. 검은색이나 흰색 창이 뜨고 `%` 표시 뒤에서 커서가 깜빡이면 준비된 것입니다.

## 2. Node 버전 확인

```bash
node -v
```

`v22.13.0` 이상이면 다음 단계로 넘어갑니다. 이보다 낮거나 `command not found`가 나오면 아래를 실행합니다(이 맥에는 nvm이 이미 설치되어 있습니다).

```bash
nvm install 22
nvm use 22
```

## 3. 코드 받기

홈 폴더에 프로젝트를 받습니다.

```bash
cd ~
git clone -b feat/uat-editorial-mcp https://github.com/yerielk/LT_THEGLEANERS.git
cd LT_THEGLEANERS
```

이미 받아 둔 적이 있다면 위 대신 이렇게 최신 코드로 맞춥니다.

```bash
cd ~/LT_THEGLEANERS
git fetch
git checkout feat/uat-editorial-mcp
git pull
```

저장소가 비공개라서 GitHub 아이디와 비밀번호를 물어보면, 비밀번호 칸에는 GitHub 비밀번호가 아니라 Personal Access Token을 넣어야 합니다. 번거로우면 `brew install gh` 후 `gh auth login`으로 로그인한 다음 다시 clone하면 됩니다.

## 4. VS Code로 열기

```bash
code .
```

`command not found: code`가 나오면 VS Code를 직접 열고 `Cmd + Shift + P`를 누른 뒤 `Shell Command: Install 'code' command in PATH`를 실행하고 터미널을 새로 열어 다시 시도합니다. 아니면 VS Code 메뉴의 **File > Open Folder**에서 홈 폴더 안의 `LT_THEGLEANERS`를 선택해도 됩니다.

VS Code 안에서도 터미널을 쓸 수 있습니다. 메뉴 **Terminal > New Terminal** (단축키 `` Ctrl + ` ``)을 누르면 화면 아래에 프로젝트 폴더에서 시작하는 터미널이 열립니다.

## 5. 패키지 설치

```bash
npm install
```

1분 안팎 걸립니다. 마지막에 `added ... packages`가 보이면 완료입니다.

## 6. `.env` 파일 만들기

**`.env`는 프로젝트 맨 위 폴더, 즉 `package.json`과 같은 위치에 있어야 합니다.**
전체 경로로는 `/Users/본인계정/LT_THEGLEANERS/.env`이고, 다른 폴더(예를 들어 `src`나 `scripts`)에 두면 읽히지 않습니다.

1. 예시 파일을 복사합니다.

   ```bash
   cp .env.example .env
   ```

2. MCP 쓰기 키로 쓸 임의의 값을 만듭니다. 출력된 긴 문자열을 복사해 둡니다.

   ```bash
   node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
   ```

3. VS Code 왼쪽 파일 목록에서 `.env`를 클릭해 엽니다. 목록에 안 보이면 터미널에서 `code .env`를 실행합니다.
4. 아래 두 줄을 채우고 `Cmd + S`로 저장합니다. 따옴표나 띄어쓰기 없이 `=` 바로 뒤에 붙여 씁니다.

   ```
   LECTA_MCP_WRITE_KEY=방금_복사한_긴_문자열
   OPENAI_API_KEY=sk-로_시작하는_OpenAI_키
   ```

   나머지 줄(`DEMO_MODE=true`, `MCP_PORT=3333` 등)은 그대로 둡니다. `OPENAI_API_KEY`는 LLM 에이전트 시연(`npm run agent:demo`)에만 필요하고, 비워 두어도 웹과 MCP와 Inspector 시연은 모두 됩니다.

`.env`는 `.gitignore`에 들어 있어서 커밋되지 않습니다. 키를 슬랙이나 카톡, 스크린샷에 올리지 마세요.

## 7. OpenAI API 키 발급

1. https://platform.openai.com 에 접속해 로그인합니다(ChatGPT 계정으로 로그인 가능).
2. 오른쪽 위 톱니바퀴 **Settings**에서 **API keys**로 들어갑니다.
3. **Create new secret key**를 누르고 이름(예: `lecta-uat`)을 정해 만듭니다.
4. `sk-`로 시작하는 키가 **한 번만** 보이므로 바로 복사해서 `.env`의 `OPENAI_API_KEY=` 뒤에 붙여 넣습니다.
5. **Settings > Billing**에서 **Add credit**으로 크레딧을 충전합니다(최소 5달러). ChatGPT Plus 구독과 API 요금은 별개라서 Plus가 있어도 크레딧이 없으면 API가 동작하지 않습니다.

기본 모델은 `.env`의 `OPENAI_MODEL=gpt-4.1-mini`이고, 이 모델은 2027년 1월 14일까지 API에서 제공된다고 안내되어 있어 이번 학기 시연에는 그대로 써도 됩니다. 시연 한 번에 드는 비용은 1센트 안팎입니다.

## 8. 데이터베이스 준비

```bash
npm run db:setup
```

작품 82개와 예시 전시가 `data/lecta.db`에 들어갑니다. 여러 번 실행해도 안전합니다.

## 9. 서버 켜기 (터미널 창 두 개)

**첫 번째 창**: 웹앱

```bash
npm run build && npm start
```

`Ready`가 보이면 브라우저에서 http://localhost:3000 을 엽니다. 개발 중이라 수정을 바로 보고 싶다면 `npm run dev`를 써도 됩니다.

**두 번째 창**: MCP 서버. `Cmd + T`로 새 탭을 열고 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
cd ~/LT_THEGLEANERS
npm run mcp:dev
```

`[mcp] Lecta MCP server on http://127.0.0.1:3333/mcp`가 나오면 켜진 것입니다. 바로 아래 줄에 `write key configured`가 보여야 쓰기 키가 제대로 읽힌 것입니다. 이 두 창은 시연이 끝날 때까지 닫지 않습니다.

## 10. 시연 전 점검 (세 번째 창)

`Cmd + T`로 탭을 하나 더 열고 실행합니다.

```bash
cd ~/LT_THEGLEANERS
npm run mcp:smoke
```

마지막에 `[mcp:smoke] PASS`가 나오면 MCP 쪽은 준비 끝입니다. 이어서 브라우저에서 http://localhost:3000/agent-lab 을 열어 서버가 online으로 보이는지, **Run protocol test**를 눌러 결과가 나오는지 확인합니다.

## 11. UAT 3번 시연 방법

**방법 A, MCP Inspector**

```bash
npm run mcp:inspect
```

브라우저에 Inspector가 열리면 Transport는 **Streamable HTTP**, URL은 `http://127.0.0.1:3333/mcp`로 두고 **Connect**를 누릅니다. **Tools** 탭에서 **List Tools**를 누른 뒤 `find_related_works`를 고르고 아래 값을 넣어 **Run Tool**을 누릅니다.

- `seed_work_ids`: `w_film_mood_for_love`, `w_book_remains_of_day`
- `target_media`: `book`
- `limit`: `3`

The Sense of an Ending, Giovanni's Room, Stoner가 ID와 함께 나오면 성공입니다.

**방법 B, 실제 LLM 에이전트** (`OPENAI_API_KEY`를 넣었을 때)

```bash
npm run agent:demo
```

모델이 MCP 도구 목록을 보고 스스로 도구를 골라 호출하는 과정이 출력됩니다. 전시 초안을 쓰기 전에 `(y/N)`을 물어보면 `y`를 입력하고 Enter를 누르세요. 원하는 요청을 직접 주고 싶다면 따옴표 안에 문장을 넣습니다.

```bash
npm run agent:demo "In the Mood for Love와 비슷한 정서의 책 3권을 찾아줘"
```

## 12. 끝낼 때

각 터미널 창에서 `Ctrl + C`를 누르면 서버가 멈춥니다.

## 자주 생기는 문제

| 증상 | 해결 |
| --- | --- |
| `EADDRINUSE: address already in use :3000` 또는 `:3333` | 이미 켜진 서버가 있습니다. `lsof -i :3000`으로 PID를 확인하고 `kill PID번호`로 끈 뒤 다시 실행합니다 |
| `.env`를 고쳤는데 반영이 안 됨 | 서버 두 개를 `Ctrl + C`로 끄고 다시 켭니다 |
| `agent:demo`가 `model credentials missing` | `.env`가 프로젝트 맨 위 폴더에 있는지, `OPENAI_API_KEY=` 뒤에 키가 붙어 있는지 확인합니다 |
| `model API error 401` | 키를 잘못 복사했거나 삭제된 키입니다. 새로 발급합니다 |
| `model API error 429` 또는 `insufficient_quota` | 크레딧이 없습니다. Billing에서 충전합니다 |
| 쓰기 단계에서 `UNAUTHORIZED` | `.env`의 `LECTA_MCP_WRITE_KEY`가 비어 있습니다. 채우고 MCP 서버를 다시 켭니다 |
| 포스터 대신 글자 표지가 보임 | 인터넷 연결 문제입니다. 기능에는 영향이 없습니다 |
